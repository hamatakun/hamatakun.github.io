# Googleスプレッドシート連携の設定

1. Googleスプレッドシートを新規作成 →「拡張機能」→「Apps Script」
2. `Code.gs` の中身を、このフォルダの `Code.gs` に置き換えて保存
3. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に
   `TOKEN` = 好きな合言葉（長めの文字列）を追加
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **全員**
5. 表示された `https://script.google.com/macros/s/…/exec` を、
   アプリの「⚙ 設定 → クラウド連携」に合言葉と一緒に貼り付け

「クラウドに保存」で台帳がシート「台帳」に上書き保存され、
「クラウドから読込」でシートの内容がアプリに復元されます。
URLと合言葉を知っている人は台帳を読み書きできるため、他人に共有しないでください。
