# 👋 ようこそ！配達員コミュニティへ

Uber Eats・出前館・Wolt・menu などで働く配達員のためのサーバーです。

**はじめにやること**
1️⃣ 📌ルール を読む
2️⃣ 🙋自己紹介 でひとこと挨拶（テンプレはチャンネル説明にあります）
3️⃣ 使っているサービスと車両のロールをつける

**こんな使い方ができます**
・📊今日の稼働報告 … 今日の件数や売上をシェアしてモチベUP
・🔥ブースト・クエスト情報 … 稼げるタイミングを共有
・❓質問・相談 … わからないことは気軽に質問（1件1スレッド）
・🗾地域情報 … 駐輪場・待機場所・トイレなどのローカル情報
・🧾確定申告・経費 … 個人事業主としてのお金の話
・🛵稼働中おしゃべり … 配達しながら（※操作は停車中に）おしゃべり

わからないことがあれば 🔰初心者部屋 へどうぞ！
