# 🛵 配達員コミュニティ Discord サーバー

Uber Eats・出前館・Wolt・menu などの配達員が **交流** と **情報発信・共有** をするための Discord サーバーの設計と、自動構築スクリプトです。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `server.json` | ロール・カテゴリ・チャンネルの設計図（ここを編集すれば構成を変えられます） |
| `rules.md` | 📌ルール チャンネルに投稿されるルール文 |
| `welcome.md` | 👋はじめに チャンネルに投稿される案内文 |
| `setup_server.py` | `server.json` の通りにサーバーを一括構築するスクリプト（最初に1回だけ） |
| `bot.py` | 認証・スパム対策・お題投稿をする見張りBot（ずっと動かしておく） |
| `config.json` | 見張りBotの設定（NGワード、連投の基準、お題リストなど） |
| `guard.py` / `test_guard.py` | スパム判定ロジックとそのテスト |

## サーバー構成

```
📢 インフォメーション   📌ルール / ✅認証 / 📣お知らせ / 👋はじめに（運営のみ書き込み）
──── ここから下は「認証して配達員ロールがついた人」だけが見られる ────
💬 交流                 🙋自己紹介 / 💬雑談 / 📊今日の稼働報告 / 🔰初心者部屋 / 😂配達あるある
📰 情報発信             ❓質問・相談(フォーラム) / 🔥ブースト・クエスト情報
                        🍔uber-eats / 🍱出前館 / 🔵wolt / 🟠menu / 🚀その他サービス
                        🗾地域情報(フォーラム：エリアごとにスレッド)
🛵 装備・車両・安全     🚲自転車・バイク / 🎒装備・グッズ / ⚠️事故・トラブル相談
💰 お金・税金           🧾確定申告・経費 / 🛡️保険・労災
🔊 ボイス               🛵稼働中おしゃべり / ☕休憩ラウンジ / 🎙️イベント
🛠 運営（非公開）       運営会議 / 通報・対応ログ / 運営VC
```

**ロール**
- 運営（管理者）／モデレーター（メッセージ削除・タイムアウト・キック・BAN）
- ベテラン配達員／配達員
- サービス：Uber Eats・出前館・Wolt・menu・Rocket Now
- 車両：自転車・原付・バイク・軽貨物・徒歩

## 構築手順

### 1. サーバーを作る
Discord アプリで「サーバーを追加」→「オリジナルの作成」→「自分と友達のため」で空のサーバーを作ります。
「設定 → 詳細設定 → 開発者モード」をONにし、サーバー名を右クリック →「サーバーIDをコピー」。これが `GUILD_ID` です。

### 2. Bot を作る
1. https://discord.com/developers/applications で「New Application」
2. 左メニュー「Bot」→「Reset Token」でトークンをコピー（これが `DISCORD_TOKEN`。**絶対に人に見せない・GitHubに上げない**）
3. 「OAuth2 → URL Generator」で Scopes に `bot`、Bot Permissions に `Administrator` をチェック
4. 表示されたURLを開いて、1で作ったサーバーに招待

### 3. スクリプトを実行
```bash
cd discord-server
pip install -r requirements.txt

python setup_server.py --dry-run          # まず内容を確認
DISCORD_TOKEN=xxxx GUILD_ID=1234567890 python setup_server.py
```
（Windows の PowerShell なら `$env:DISCORD_TOKEN="xxxx"; $env:GUILD_ID="1234567890"; python setup_server.py`）

何度実行しても大丈夫です。すでにある同名のロール・チャンネルはそのまま使います。
このあと同じBotを見張り役として使います（次の手順）。

### 4. 見張りBotを動かす
`setup_server.py` に使ったのと同じBotでOKです（構築後もサーバーから外さないでください）。

**① Developer Portal の設定**（https://discord.com/developers/applications → 自分のBot → 「Bot」）
- `SERVER MEMBERS INTENT` と `MESSAGE CONTENT INTENT` を **ON** にする

**② Botのロールの位置**
サーバー設定 → ロール で、Botのロール（Botと同じ名前）を **「配達員」や一般ロールより上** にドラッグ。
下にあるとロール付与やタイムアウトができません。

**③ 起動**
```bash
DISCORD_TOKEN=xxxx GUILD_ID=1234567890 python bot.py
```
起動すると ✅認証 チャンネルに認証ボタンが自動で置かれます。

Botは**動かしている間だけ**働きます。24時間動かすには、つけっぱなしのPC、
またはレンタルサーバー（VPS、月数百円〜）などで動かしてください。

#### 見張りBotがやること
| 機能 | 内容 |
| --- | --- |
| ✅ 認証 | ボタン → かんたんな足し算に答えると「配達員」ロールを付与。**作成7日未満のアカウントは認証不可**（使い捨てスパム垢対策）。3回間違えると10分待ち |
| 🚫 連投 | 8秒に6回以上 → 削除＋30分タイムアウト＋直近2分の投稿をまとめて削除 |
| 🚫 コピペ拡散 | 同じ文を60秒以内に3チャンネル以上 → 同上（乗っ取られたアカウントの典型） |
| 🚫 メンション爆撃 | 5人以上メンション、`@everyone` `@here` → 同上 |
| 🔗 リンク | 他サーバーの招待リンクは削除。参加から24時間以内の人のリンクも削除 |
| 🤬 NGワード | 闇バイト募集・Nitro詐欺などの定番フレーズを削除（注意喚起の会話は消えないよう、募集っぽい言い回しだけ登録） |
| 🚨 レイド | 60秒に10人以上参加 → 15分間認証を停止して運営に通知 |
| 👋 歓迎 | 認証した人を 💬雑談 で歓迎し、🙋自己紹介 へ案内 |
| 💡 今日のお題 | 毎日12時に 💬雑談 へ会話のお題を投稿（話題がなくても会話が生まれる） |

運営（メッセージ管理権限がある人）の投稿はチェックしません。対応した内容はすべて 🛠運営 › 通報・対応ログ に記録され、本人にもDMで理由が届きます。

**運営用コマンド**
- `/lockdown 分数` … 荒らしが来たときに認証を止める（`/lockdown 0` で解除）
- `/お題` … 今すぐお題を投稿

数値・NGワード・お題は `config.json` で変更できます（変更後はBotを再起動）。

### 5. 手動でやる仕上げ（Discord の画面から）
1. **コミュニティを有効化**：サーバー設定 →「コミュニティを有効にする」。ルールチャンネルに 📌ルール、更新チャンネルに 📣お知らせ を指定
2. **オンボーディング**：サーバー設定 →「オンボーディング」で質問を作成
   - 「使っているサービスは？」→ Uber Eats / 出前館 / Wolt / menu / Rocket Now ロール
   - 「車両は？」→ 自転車 / 原付・バイク / 軽貨物 / 徒歩 ロール
   - 回答するとロールが自動付与され、自己紹介代わりになります
3. **認証レベル**：サーバー設定 → 安全設定 で「メール認証済みのアカウントのみ」以上にする
4. **AutoMod**：サーバー設定 → AutoMod で「スパム」「よく使われる不適切な言葉」をON。
   キーワードに `闇バイト` `高額報酬` `即日払い` `受け子` `紹介コード` などを追加し、ブロック＋運営チャンネルへ通知
5. 📣お知らせ を「アナウンスチャンネル」に変換（他サーバーからフォローできるようになります）
6. 自分に「運営」ロールを付ける

## 運営のコツ
- **最初の1〜2週間は運営が率先して投稿**する（稼働報告・ブースト情報など）。空っぽのサーバーには人が書き込みません
- 定期企画の例：月1の「確定申告・経費相談会」VC、週1の「今週の稼働ランキング」、季節ごとの「雨・夏・冬の装備まとめ」
- よく出る質問は ❓質問・相談 の解決済みスレッドを 👋はじめに にリンクして FAQ 化
- 人が増えたら 🗾地域情報 のスレッドを地域別チャンネルに格上げ（`server.json` に追加して再実行）
- 紹介コードの宣伝は荒れやすいので、許可制か専用チャンネルにまとめる

## 構成を変えたいとき
`server.json` を編集して再実行するだけです。

```json
{ "name": "チャンネル名", "type": "text | voice | forum", "topic": "説明", "readonly": true, "post": "投稿するファイル.md" }
```
カテゴリに `"staff_only": true` をつけると運営・モデレーターだけが見られます。
