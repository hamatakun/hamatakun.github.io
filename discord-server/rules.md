# 📌 サーバールール

配達員どうしが安心して交流・情報交換できる場所にするためのルールです。参加した時点で同意したものとみなします。

**1. お互いを尊重する**
誹謗中傷・差別・晒し・しつこい勧誘は禁止。初心者の質問をバカにしない。

**2. お客様・店舗・他人の個人情報を出さない**
住所、氏名、電話番号、建物や表札の写真、注文内容がわかるスクショはNG。
スクショを貼るときは必ず個人情報を隠してください。

**3. 規約違反・違法行為の話は禁止**
アカウントの貸し借り・売買（名義貸し）、不正な位置偽装、危険運転・交通違反の自慢などは禁止。

**4. 怪しい仕事の勧誘は即BAN**
「高額」「即日」「荷物を受け取るだけ」などの闇バイト勧誘、副業・投資・情報商材の宣伝はすべて禁止です。DMで誘われたら運営に報告してください。

**5. 宣伝は運営の許可制**
紹介コード・招待リンク・自分のSNSやYouTubeの宣伝は、運営の許可を得てから。

**6. 情報は正確に、出どころを書く**
報酬・仕様変更などは「いつ／どの地域／どこで見た情報か」を添えてください。不確かなものは「未確認」と書く。

**7. チャンネルの用途を守る**
質問は ❓質問・相談 に1件1スレッドで。迷ったら 💬雑談 へ。

**8. 運転中にDiscordを操作しない**
ボイスチャンネルを聞くのはOKでも、画面操作は必ず停車してから。安全第一。

違反があった場合は、注意 → 一時ミュート → キック／BAN の順で対応します（悪質な場合は即BAN）。
困ったこと・通報は運営またはモデレーターにDMしてください。
